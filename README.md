# InstaPulse — AI-Powered Social Media Engagement Analytics

> IBM SkillBuild Final Project | Data Analytics with AI

---

## Project Overview

**InstaPulse** is a data analytics and AI project that analyzes social media post performance across 6 platforms (Instagram, TikTok, YouTube, Facebook, Twitter, LinkedIn) and predicts engagement performance using a machine-learning model trained on a real dataset of 5,000 posts.

The project demonstrates a complete data science workflow:

**Dataset → Data Processing → Analysis → Visualizations → Machine Learning → Prediction → Web Dashboard**

---

## Problem Statement

Content creators and marketers struggle to understand what makes a social media post perform well. Without data-driven insights, decisions about platform choice, content type, posting time, and audience targeting are made by guesswork. InstaPulse solves this by analyzing historical post data and using AI to predict whether a new post will achieve **Low**, **Medium**, or **High** engagement.

---

## Objectives

- Perform exploratory data analysis on 5,000 social media posts
- Identify key factors that drive high engagement
- Build a machine-learning classifier to predict engagement performance
- Deploy an interactive analytics dashboard with AI prediction capability

## Machine Learning Approach

- **Model:** Random Forest Classifier (100 trees)
- **Target:** Engagement Performance — 3 classes:
  - **Low** (Engagement Rate ≤ 1.36%)
  - **Medium** (1.36% < Rate ≤ 4.14%)
  - **High** (Rate > 4.14%)
- **Features:** Platform, Content Type, Category, Follower Count, Hashtag Count, Content Length, Hour of Day, Day of Week, Sentiment, Influencer Tier, Has Media, Is Verified
- **Train/Test Split:** 80% / 20% (stratified)
- **Accuracy:** 71.4%
- **Top Features:** Follower Count (23.6%), Platform (15.6%), Content Length (12.7%)

## Installation

### Prerequisites
- Python 3.9 or higher
- Node.js 18 or higher

### Step 1 — Install Python dependencies

```bash
pip install -r requirements.txt
```

---

## How to Run

### Step 1 — Run the Python Analytics & ML File

This generates analytics, visualizations, and saves the trained model.

```bash
python TeliMushera_InstaPulse.py
```

Expected output:
- `InstaPulse/analytics_plots.png` — 6 analytics charts
- `InstaPulse/confusion_matrix.png` — model confusion matrix
- `InstaPulse/backend/model_data.pkl` — trained model file

---

### Step 2 — Start the FastAPI Backend

```bash
cd InstaPulse/backend
uvicorn main:app --reload --port 8000
```

The API will be available at: `http://localhost:8000`

API documentation: `http://localhost:8000/docs`

---

### Step 3 — Start the React Frontend

Open a **new terminal window**:

```bash
cd InstaPulse/frontend
npm install
npm run dev
```

The dashboard will be available at: `http://localhost:5173`
